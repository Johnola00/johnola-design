# John Oduntan Portfolio

A dark, cinematic personal portfolio for John Oduntan, a UI/UX designer and frontend developer.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Run locally

Install Node.js, then run:

```bash
corepack enable
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Brand assets

Replace the temporary SVG files while keeping these names:

- `public/brand/john-oduntan-logo.svg` — 40 × 37 px
- `public/icons/substack.svg` — 38 × 38 px
- `public/icons/x.svg` — 38 × 38 px
- `public/icons/linkedin.svg` — 38 × 38 px
- `public/icons/behance.svg` — 38 × 38 px

SVG is preferred because it stays sharp at every screen density.
