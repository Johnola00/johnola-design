# Johnola Design

Personal portfolio of John Oduntan, a Product Designer & AI Builder based in Lagos, Nigeria.

This site contains selected product design work across web and mobile, including case studies, product experiments, and projects exploring how design, frontend development, and AI can be used to turn ideas into working digital products.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
